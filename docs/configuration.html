YYourApp Framework docs

Configuration

Environment variables in .env feed plain PHP arrays in config/, read anywhere with config().

The .env file

.env is loaded by load_env() at bootstrap. Real environment variables win over the file, so a server can override any value without editing it. The file is never committed; .env.example documents every key.

APP_NAME=YourApp
APP_ENV=local
APP_DEBUG=true
APP_URL=
APP_BASE_PATH=
APP_TIMEZONE=UTC
APP_KEY=base64:...        # console key:generate
LOG_LEVEL=debug

SESSION_NAME=app_session
SESSION_LIFETIME=120
SESSION_SECURE_COOKIE=false
HSTS_ENABLED=false

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=myapp
DB_USERNAME=root
DB_PASSWORD=
DB_CHARSET=utf8mb4

Syntax: KEY=value, # comments, export KEY=value, single or double quotes around values containing spaces or #. env('KEY', $default) converts true, false, null and empty to the PHP values.

Config files

Each file in config/ returns an array. config('file.key.subkey', $default) loads the file once and walks the dots; config_set() overrides a value for the rest of the request (useful in tests).

FileContents
app.phpname, env, debug, url, base_path, timezone, key, log_level, asset_versioning
auth.phpUser model, username column, session key, login and home route names, policies, remember-me cookie
container.phpDependency injection bindings, singletons, aliases
database.phpdefault connection, connections (mysql, sqlite, testing), log_queries, slow_query_ms
security.phpResponse headers, Content-Security-Policy directives, HSTS switch
session.phpCookie name, idle lifetime in minutes, path, domain, secure flag, SameSite
view.phpTemplate and compile directories, escaping, compile checks, Smarty functions and modifiers

Reading configuration

config('app.name');                          // "YourApp"
config('database.connections.mysql.host');   // "127.0.0.1"
config('mail.from', 'noreply@example.com');  // default when the key or file is missing
config_set('app.name', 'Renamed');           // for this request only

Config::has('app.key');                      // true when defined, even if null

Key settings explained

APP_DEBUG

Shows exception pages with code excerpts and stack traces, keeps a query log for the debug page, re-compiles templates when they change, and reads routes/web.php on every request instead of the route cache. Never enable it in production: it reveals file paths and internal messages.

APP_URL and APP_BASE_PATH

Both are optional. The base path (for example /saikat/test1 when the app lives in a sub-directory) is derived from SCRIPT_NAME; set APP_BASE_PATH only when a proxy hides it. app_url() uses APP_URL when set, otherwise the request's scheme and host.

APP_KEY

The secret used to sign remember-me tokens (an HMAC of the cookie token is stored in the database). Generate it with console key:generate.

LOG_LEVEL

The lowest level written to storage/logs: debug, info, notice, warning, error, critical.

SESSION_LIFETIME

Idle timeout in minutes; a session untouched for that long is discarded. The cookie itself lasts until the browser closes; persistent logins use remember-me instead.

DB_CONNECTION

Name of the default connection in config/database.php. Models and Database::table() use it unless told otherwise.

Config files are ordinary PHP, so a value may be a closure. That is how config/container.php declares factories for services.
