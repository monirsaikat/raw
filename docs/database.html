Database and queries

Named PDO connections, a fluent query builder that validates identifiers and binds every value, collections, pagination and a date value type.

Connections

config/database.php declares connections and the default one (DB_CONNECTION):

'default' => env('DB_CONNECTION', 'mysql'),
'connections' => [
    'mysql'   => ['driver' => 'mysql', 'host' => ..., 'database' => ..., 'username' => ..., 'password' => ..., 'charset' => 'utf8mb4'],
    'sqlite'  => ['driver' => 'sqlite', 'database' => 'storage/database.sqlite'],   // relative to the project root
    'testing' => ['driver' => 'sqlite', 'database' => ':memory:'],
],
Database::connection();               // default Connection, opened lazily
Database::connection('sqlite');       // another one
Database::addConnection('reports', ['driver' => 'mysql', ...]);   // at runtime
Database::purge('reports');           // close and forget

Supported drivers are mysql (MySQL and MariaDB) and sqlite. A failed connection throws a RuntimeException whose stack trace never includes the password.

Raw queries

The static Database helpers use the default connection; a Connection object offers the same methods.

Database::select('SELECT * FROM users WHERE active = ?', [1]);          // array of rows
Database::selectOne('SELECT * FROM users WHERE id = ?', [$id]);          // row or null
Database::scalar('SELECT COUNT(*) FROM users');                          // first column of the first row
Database::insert('INSERT INTO tags (name) VALUES (?)', ['php']);         // last insert id
Database::update('UPDATE users SET active = ? WHERE id = ?', [0, $id]); // affected rows
Database::delete('DELETE FROM sessions WHERE expires_at < ?', [now()]);
Database::statement('ALTER TABLE users ADD INDEX ...');
Database::unprepared('CREATE TABLE ...');                               // no prepared statement

foreach (Database::cursor('SELECT * FROM logs') as $row) { ... }         // streamed, one row at a time

Bindings are typed: integers bind as integers, booleans as 0/1, DateTimeInterface objects as Y-m-d H:i:s strings. Never interpolate request data into the SQL string; every raw helper takes bindings only.

Transactions

Database::transaction(function () {
    $order = Order::create([...]);
    $order->items()->createMany($items);
});                                            // commits, or rolls back and rethrows

Database::transaction(fn () => ..., attempts: 3);   // retries on deadlock

Database::transaction(function () {
    Database::transaction(fn () => ...);       // nested → SAVEPOINT; the inner one can roll back alone
});

Database::beginTransaction();  Database::commit();  Database::rollBack();  Database::transactionLevel();

Errors and logging

A failed statement throws QueryException; its message contains the SQL with bindings interpolated, and ->sql, ->bindings and ->sqlState() are available. With APP_DEBUG=true (or DB_LOG_QUERIES=true) every query is kept in a log that the debug page shows. DB_SLOW_QUERY_MS logs slower queries as warnings. Database::listen(fn ($sql, $bindings, $ms) => ...) observes every query.

The query builder

Database::table('users') starts a query; models start one with Post::query() or any forwarded static call. Column and table names are validated and quoted, operators are whitelisted, values are bound. Request data may be a value, never a column or operator.

Selecting

Database::table('posts')->get();                                   // Collection of arrays
Database::table('posts')->select('id', 'title')->get();
Database::table('posts')->selectRaw('COUNT(*) AS n, status')->groupBy('status')->get();
Database::table('users as u')->select('u.name')->distinct()->get();
Database::table('users')
    ->selectSub(fn ($q) => $q->from('posts')->selectRaw('COUNT(*)')->whereColumn('posts.user_id', 'users.id'), 'posts_count')
    ->get();

Where clauses

->where('status', 'published')                 // =
->where('views', '>=', 100)                    // =, <, >, <=, >=, <>, !=, like, not like
->where(['status' => 'published', 'featured' => 1])
->where(fn ($q) => $q->where('a', 1)->orWhere('b', 2))     // parenthesised group
->orWhere('author_id', $id)
->whereNot('role', 'admin')
->whereIn('id', [1, 2, 3])                      // an empty array matches nothing
->whereIn('id', fn ($q) => $q->from('admins')->select('user_id'))   // sub-query
->whereNotIn('id', [...])
->whereNull('deleted_at')  ->whereNotNull('published_at')
->whereBetween('price', [10, 20])  ->whereNotBetween(...)
->whereLike('name', 'A%')  ->whereNotLike(...)  ->orWhereLike(...)
->whereColumn('updated_at', '>', 'created_at')
->whereDate('created_at', '2026-09-07')  ->whereYear('created_at', 2026)  ->whereMonth(...)  ->whereDay(...)
->whereExists(fn ($q) => $q->from('logins')->whereColumn('logins.user_id', 'users.id'))
->whereRaw('YEAR(created_at) = ?', [2026])      // trusted SQL only

Passing null as the value produces IS NULL (or IS NOT NULL with !=). Comparing against a QueryBuilder or closure produces a sub-select.

Joins, grouping, ordering

->join('users', 'users.id', '=', 'posts.user_id')
->leftJoin('profiles', function (JoinClause $join) {
    $join->on('users.id', '=', 'profiles.user_id')->where('profiles.active', 1);
})
->crossJoin('settings')
->groupBy('status')->having('n', '>', 5)->havingRaw('COUNT(*) > ?', [2])
->orderBy('created_at', 'desc')  ->orderByDesc('id')  ->latest()  ->oldest()  ->inRandomOrder()  ->reorder()
->limit(10)->offset(20)  ->take(10)->skip(20)  ->forPage(3, 10)
->lockForUpdate()  ->sharedLock()
->union($other)  ->unionAll(fn ($q) => $q->from('archive'))
->when($search, fn ($q, $term) => $q->whereLike('title', "%$term%"))
->unless($includeDrafts, fn ($q) => $q->where('published', 1))

Writing

Database::table('tags')->insert(['name' => 'php']);
Database::table('tags')->insert([['name' => 'a'], ['name' => 'b']]);        // multiple rows
$id = Database::table('tags')->insertGetId(['name' => 'sql']);
Database::table('tags')->insertOrIgnore([...]);
Database::table('tags')->upsert([['name' => 'x', 'hits' => 1]], 'name', ['hits']);   // insert or update on conflict
Database::table('posts')->where('id', 3)->update(['title' => 'New']);
Database::table('posts')->updateOrInsert(['slug' => 'a'], ['title' => 'A']);
Database::table('posts')->where('id', 3)->increment('views');  ->decrement('stock', 2);
Database::table('posts')->where('id', 3)->delete();
Database::table('logs')->truncate();

Database::raw('NOW()') marks a trusted fragment that is inserted verbatim instead of bound.

Collections

Every get() returns a Collection: iterable, countable, array-accessible and JSON-serialisable, with a fluent API. collect([...]) builds one from an array.

$users->pluck('email');                          $users->pluck('name', 'id');
$users->keyBy('id');                             $users->groupBy('team.name');
$users->where('active', true)->sortBy('name');   $users->first(fn ($u) => $u->id > 5);
$users->map(fn ($u) => $u->email)->unique();     $users->filter()->values();
$users->sum('balance');  ->avg()  ->max()  ->count()  ->isEmpty()
$users->chunk(50);  ->take(5);  ->skip(5);  ->reverse();  ->shuffle();  ->random()
$users->contains('id', 3);  ->every(fn)  ->some(fn)  ->partition(fn)
$users->toArray();  ->toJson();  ->each(fn)  ->tap(fn)  ->pipe(fn)  ->when($cond, fn)
$posts->load('author');                          // eager load onto models already fetched

Methods that read a key (pluck, where, sortBy, groupBy…) accept dot.paths and work on arrays, objects and models alike. Filtering methods preserve keys; call values() to reindex.

Pagination

$posts = Post::latest()->paginate(20);             // reads ?page= from the query string
$posts = Post::latest()->paginate(20, page: 3, pageName: 'p');
$posts = Post::latest()->simplePaginate(20);      // no COUNT query, only "has more"
{foreach $posts as $post} ... {/foreach}
{$posts->links()|raw}                             {* Bootstrap 5 pagination *}
Showing {$posts->firstItem()}–{$posts->lastItem()} of {$posts->total()}

Paginator exposes total(), perPage(), currentPage(), lastPage(), hasMorePages(), nextPageUrl(), previousPageUrl(), url($page), appends([...]), withQueryString(), withPath() and forwards collection methods to its items. Returned from an action it serialises to the usual data / current_page / last_page / … JSON shape.

Dates

Timestamp attributes and now() are DateTimeValue objects: immutable, printing as Y-m-d H:i:s, with helpers.

now()->addDays(3);  ->subMinutes(5);  ->startOfDay();  ->endOfMonth();
now()->diffForHumans();                      // "just now", "3 days ago", "in 2 hours"
$post->created_at->toDateString();  ->format('d M Y');  ->isPast();  ->isToday();  ->diffInDays($other)
DateTimeValue::parse('2026-09-07 10:00');    DateTimeValue::fromFormat('d/m/Y', '07/09/2026');
today();

Identifier rules

Table and column names must match [A-Za-z_][A-Za-z0-9_]*, optionally qualified (users.id) or aliased (users.name as author). Anything else throws InvalidArgumentException, which is what stops a user-controlled sort column from becoming an injection. Order directions must be asc or desc.
