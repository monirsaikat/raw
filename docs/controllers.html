Controllers

Plain classes in controllers/. Methods receive injected dependencies and route parameters, and return whatever should be sent.

A controller

php console.php make:controller Post      # controllers/PostController.php
<?php

class PostController
{
    public function __construct(private PostRepository $posts)
    {
    }

    public function index()
    {
        return view('posts/index', ['posts' => Post::latest()->paginate(20)]);
    }

    public function show(Post $post)
    {
        return view('posts/show', ['post' => $post->load('author', 'comments')]);
    }

    public function store()
    {
        $data = validated(input(), ['title' => 'required|max:150', 'body' => 'required']);

        $post = auth_user()->posts()->create($data);

        return redirect_route('posts.show', ['id' => $post->id]);
    }

    public function destroy(Post $post)
    {
        authorize('delete', $post);
        $post->delete();

        return redirect_route('posts.index');
    }
}

Nothing needs to be extended. Constructor parameters are resolved by the container; PostRepository above is any class you write in services/.

How parameters are filled

For each parameter of the action, in order:

  1. A parameter typed with a model class receives the record for the next route parameter: Post::findOrFail($id). A missing record answers 404 before the method runs. Soft-deleted rows are not found.
  2. A parameter typed with any other class is resolved from the container.
  3. An untyped or scalar parameter takes the next route parameter. An absent optional segment leaves the parameter's default value in place.
get('/users/{user}/posts/{page?}', 'UserController@posts');

public function posts(PostRepository $repository, User $user, int $page = 1)
{
    // $repository from the container, $user = User::findOrFail($routeParam), $page = 1 when absent
}

Parameter names do not have to match placeholder names; order does.

Reading input

$title = input('title');                 // trimmed string or null
$page = (int) query('page', 1);          // query string only
$data = input_only(['title', 'body']);
$file = request_file('cover');           // ['name', 'tmp_name', 'size', 'type', 'error'] or null

if (has_input('remember')) { ... }
if (wants_json()) { return ['ok' => true]; }

Prefer validated() for anything that ends up in the database; it returns only the fields you declared.

Invokable controllers

A class with a single __invoke() method can be routed by name alone:

get('/report', 'ReportController');

class ReportController
{
    public function __invoke(ReportBuilder $builder)
    {
        return $builder->render();
    }
}

Testing a controller

test('store creates a post', function () {
    acting_as(User::factory()->create());

    http_post('/posts', ['title' => 'Hello', 'body' => 'World'])
        ->assertRedirect('/posts/1');

    assert_database_has('posts', ['title' => 'Hello']);
});
