Testing

A built-in runner with plain assertions, an in-process HTTP client that drives the real routes and views, and an in-memory SQLite database for anything that touches tables. No PHPUnit required.

Writing tests

Each file in tests/ registers cases with test(). State (input, session, routes, container, gate, configuration) is reset before every case.

<?php

test('slugs are lower-case and dashed', function () {
    assert_same('hello-world', str_slug('Hello World!'));
});

test('unknown routes are 404', function () {
    get('/only', fn () => 'ok');

    $e = assert_throws(fn () => route_dispatch('GET', '/other'), HttpException::class);
    assert_same(404, $e->status);
});
php console.php test              # all files
php console.php test Router       # tests/RouterTest.php and anything else containing "Router"

Output lists ok, FAIL (with the message and location) and skip per case, then a summary. The exit code is 1 when anything failed.

Assertions

assert_true, assert_false, assert_same (strict), assert_equals (loose), assert_null, assert_not_null, assert_contains, assert_not_contains, assert_matches (regex), assert_count, assert_key_exists, assert_instance_of, assert_throws($fn, $class, $messagePart) (returns the exception), fail($message), skip($reason). Every assertion takes an optional message as its last argument.

Hooks

before_each(function () { use_test_database(); http_use_app_routes(); Database::beginTransaction(); });
after_each(fn () => Database::rollBack());

Hooks apply to every test in the same file. after_each runs even when the test failed.

The HTTP client

Requests run in-process through the real middleware, controllers and templates. The session persists between calls like a browser cookie, flash data ages exactly as in production, and CSRF tokens are added automatically to unsafe requests.

http_get('/posts?page=2', ['X-Requested-With' => 'XMLHttpRequest']);
http_post('/posts', ['title' => 'Hello', 'body' => '...']);
http_put('/posts/1', [...]);   http_patch(...);   http_delete('/posts/1');      // sent as POST + _method, like a form
http_json('POST', '/api/posts', ['title' => 'Hello']);                          // JSON body, Accept: application/json
http_request('GET', '/x', [], ['Referer' => '/y'], ['REMOTE_ADDR' => '10.0.0.1']);

http_use_app_routes();          // load routes/web.php (tests start with no routes)
acting_as($user);               // subsequent requests are authenticated; acting_as(null) logs out
http_follow($response);         // follow local redirects with GET

To test a CSRF failure pass ['_token' => 'wrong']. Requests carry the previous request's URL as Referer, so back() behaves naturally.

Response assertions

Every request returns a TestResponse; assertions chain and fail with the status and any exception the action threw.

AssertionChecks
assertStatus(201), assertOk(), assertCreated(), assertNotFound(), assertForbidden(), assertUnauthorized(), assertUnprocessable(), assertServerError()Status code
assertRedirect(), assertRedirect('/login'), assertRedirectToRoute('login'), assertNoRedirect()3xx and the target path (host and base path ignored)
assertSee(), assertDontSee(), assertSeeText() (tags stripped), assertSeeInOrder([...])Body content
assertJson([...]) (subset), assertExactJson(), assertJsonPath('user.name', 'Ann'), assertJsonMissing('user.password'), assertJsonCount(3, 'items')JSON body
assertHeader('Content-Type', 'application/json; charset=utf-8'), assertHeaderMissing()Headers
assertSessionHas('key', $value), assertSessionMissing()Session after the request
assertSessionHasErrors(['email']), assertSessionHasErrors(['email' => 'The email must be a valid email address.']), assertSessionHasNoErrors(), assertValid(), assertInvalid()Validation errors flashed for the next request
assertAuthenticated($user), assertGuest()Login state

Also available: status(), body(), headers(), header($name), json('path'), dump(), and ->exception.

Database tests

before_each(function () {
    use_test_database();            // in-memory SQLite with database/migrations applied
    http_use_app_routes();
    Database::beginTransaction();
});
after_each(fn () => Database::rollBack());

test('the contact form stores a message', function () {
    http_post('/contact', ['name' => 'Ann', 'email' => 'ann@example.com', 'message' => 'Hi'])
        ->assertRedirect('/contact')
        ->assertSessionHasNoErrors();

    assert_database_has('messages', ['email' => 'ann@example.com']);
    assert_database_count('messages', 1);
    assert_database_missing('messages', ['email' => 'nobody@example.com']);
});

use_test_database() registers a connection named app_testing, makes it the default and runs the migrations once per process. The transaction in the hooks isolates each test. Factories (User::factory()->create()) are the quickest way to seed rows.

If pdo_sqlite is not available the database tests are skipped rather than run against MySQL. The test command loads the extension automatically when the DLL or shared object exists; otherwise set DB_TEST_CONNECTION to a throwaway connection defined in config/database.php.

Testing pieces in isolation

route_dispatch('GET', '/path');                            // run the pipeline for a path, get the action's return value
run_middleware(['throttle:2,1'], fn () => 'core');         // a middleware chain by itself
render_exception(new HttpException(404));                  // the Response an exception would produce
validate(['email' => 'x'], ['email' => 'required|email']); // the error array
config_set('app.name', 'Test');                            // for this test only
test_next_request();                                       // age flash data without an HTTP request
app()->instance(Mailer::class, new FakeMailer());          // swap a service

The framework's own suite

tests/ ships with about two hundred cases covering routing, middleware, validation, the query builder, models and relationships, the schema builder, sessions, caching, errors, the container, authorization, the HTTP client and the full application flow. They double as executable examples; tests/AppFlowTest.php is the best starting point for writing your own.
