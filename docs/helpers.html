Helpers reference

Every global function, grouped by area. Internal functions used only by the framework are omitted.

Routing and URLs

get / post / put / patch / delete / any ($path, $action, $name, $middleware)Register a route
route_map(array $methods, $path, $action, $name, $middleware)Register for several verbs
group(array $attributes, callable $callback)Prefix, middleware and name prefix for nested routes
route_url($name, $params)Path for a named route
url($path), app_url(), base_path()Base-path-aware URL, absolute root URL, the sub-directory prefix
current_route(), current_route_name(), route_is(...$patterns)The matched route
route_parameter($name, $default), route_parameters()Matched parameter values
route_dispatch($method, $path)Run the pipeline and return the action result

Request

input($key, $default), input()Trimmed input (query + body, JSON merged), one key or all
request($key, $default), query($key, $default)Untrimmed input; query string only
input_only([...]), input_except([...]), has_input($key)Subsets; presence with a non-empty value
request_file($key)Uploaded file array or null
old($key, $default)Input flashed by the previous request
request_method(), request_real_method()Verb with and without _method spoofing
request_path(), request_uri(), request_url(), request_host(), request_ip()Request facts
request_header($name, $default), request_is_json(), request_is_ajax(), request_is_secure(), wants_json()Headers and negotiation
request_body(), request_json()Raw body; decoded JSON body

Response

response($body, $status, $headers)A Response (arrays become JSON)
json($data, $status, $headers)JSON response
redirect($url, $status), redirect_route($name, $params, $status), back($fallback, $status)Redirects
back_with_errors($errors, $old)Flash errors and input, then redirect back
abort($status, $message, $headers), abort_if(), abort_unless()Stop with an HTTP error
url_is_local($url)Safe redirect target check
http_status_text($status)Reason phrase

Views

view($template, $data), view_exists($template)Render views/<template>.tpl
e($value)HTML-escape outside templates
asset($path)Versioned asset URL
csrf_token(), csrf_field(), csrf_meta(), csrf_verify($token)CSRF helpers
method_field($method), current_year(), csp_nonce(), navigate($params)Template tags, also callable from PHP

Validation

validated($data, $rules, $messages)Validate or throw; returns the declared fields
validate($data, $rules, $messages)Returns the error array
validator_extend($name, $rule, $message)Register a rule

Localization

app_locale(), set_locale($locale, $remember), locale_is(...), fallback_locale()The current locale
lang_available(), lang_exists($locale), lang_has($key, $locale)What is in lang/
lang_add($locale, $group, $lines), lang_reset(), lang_path($locale)Runtime lines; forget loaded files
lang_detect($parameter), lang_accepted()Best locale for the request; Accept-Language tags by quality

Authentication and authorization

auth_user($guard), auth_id($guard), auth_check($guard), auth_guest($guard)Current user of the default guard, or of a named one
guard($name), auth_guard(), auth_use_guard($name), auth_guards(), auth_guard_config($guard, $key)Guard object; the request's default guard; every guard name; a guard's settings
auth_hash($plain), auth_verify($plain, $hash)Password hashing; logins rehash automatically when the algorithm changes
auth_attempt($username, $password, $remember, $guard), auth_login($user, $remember, $guard), auth_logout($guard), auth_logout_all(), auth_intended($default, $guard)Login flow
can(), cannot(), can_any(), authorize()Checks for the current user
gate(), gate_define(), gate_policy(), gate_before(), gate_after()Gate configuration

Events, queue and mail

listen($event, $listener, $priority), event($event, ...$payload), event_until(), listeners($event), forget_listeners()Event dispatcher; wildcards such as user.*. See Events
dispatch(Job $job), dispatch_later($seconds, $job), dispatch_sync($job)Push a job onto the queue. See Queue
mailer($name), Mail::to()->send(), Mail::queue(), Mail::raw()Send mail. See Mail

Encryption, cookies, signed URLs, HTTP caching

encrypt($value), decrypt($payload), encrypt_string(), decrypt_string()AES-256-GCM with APP_KEY; DecryptException on tamper

signed_url($route, $params, $expiresIn), signed_path(), signed_url_temporary(), signed_url_valid()HMAC-signed URLs; the signed middleware rejects invalid ones
cache.headers:public,max_age=3600,etag, cache.response:ttl, response_cache_forget($url)Caching middleware. See Security and Sessions and cache
