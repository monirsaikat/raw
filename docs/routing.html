Routing

Routes live in routes/web.php. Static paths match with an array lookup, dynamic paths with regexes compiled once, and the whole table can be cached for production.

Defining routes

get('/', 'HomeController@index', 'home');
get('/about', 'HomeController@about', 'about');
post('/contact', 'ContactController@store', 'contact.store', ['throttle:10,1']);
put('/posts/{id}', 'PostController@update', 'posts.update');
patch('/posts/{id}', 'PostController@update');
delete('/posts/{id}', 'PostController@destroy', 'posts.destroy');
any('/webhook', 'WebhookController@handle');                      // GET, POST, PUT, PATCH, DELETE
route_map(['GET', 'POST'], '/search', 'SearchController@index');

Every function takes the path, the action, an optional route name and an optional list of middleware. The name is what route_url(), redirect_route() and {navigate} use, so name anything you link to.

Actions

  • 'PostController@show': a class in controllers/ and a method.
  • 'ReportController': an invokable class (__invoke).
  • [PostController::class, 'show']: a class and method pair.
  • A closure. Convenient, but closures cannot be cached by route:cache.

Controllers are built by the container, so constructor dependencies are injected. See Controllers for how parameters reach the method.

Parameters

get('/user/{id}', 'UserController@show');            // any segment
get('/user/{id:\d+}', 'UserController@show');        // regex constraint
get('/docs/{page?}', 'DocsController@show');         // optional, must be the last segment
get('/files/{path:.+}', 'FileController@show');      // may contain slashes

Values are URL-decoded and passed to the action in order. An absent optional segment is null, unless the method parameter declares a default. Inside middleware or anywhere else, route_parameter('id') and route_parameters() read the matched values by name.

Groups

group(['prefix' => '/admin', 'middleware' => ['auth', 'can:admin'], 'name' => 'admin.'], function () {
    get('/', 'AdminController@dashboard', 'dashboard');          // /admin, name admin.dashboard
    get('/users', 'AdminController@users', 'users');             // /admin/users, name admin.users

    group(['prefix' => 'reports'], function () {
        get('/daily', 'ReportController@daily', 'reports.daily'); // /admin/reports/daily
    });
});

Prefixes, middleware and name prefixes accumulate through nested groups.

Middleware on routes

get('/account', 'AuthController@account', 'account', ['auth']);
post('/login', 'AuthController@login', 'login.store', ['guest', 'throttle:5,1']);
get('/posts/{id}/edit', 'PostController@edit', 'posts.edit', ['auth', 'can:update,Post@id']);

The global middleware (csrf by default) runs first, then the route's list in order. See Middleware.

Generating URLs

route_url('home');                                        // "/"  (or "/saikat/test1/" under a sub-directory)
route_url('user', ['id' => 5]);                            // "/user/5"
route_url('user', ['id' => 5, 'tab' => 'posts']);          // "/user/5?tab=posts"  (leftovers become the query string)
url('about');                                              // "/about"
app_url();                                                 // "http://localhost/saikat/test1"
redirect_route('posts.show', ['id' => $post->id]);

Missing required parameters or unknown names throw a RuntimeException, which surfaces mistakes immediately. In templates use the Smarty tags; their output is escaped for attributes:

<a href="{navigate name='user' id=$user.id}">{$user.name}</a>
<a href="{url path='about'}">About</a>
<link rel="stylesheet" href="{asset path='assets/css/app.css'}">

The current route

current_route_name();          // "admin.users"
route_is('admin.*');           // true for any admin route
route_is('home', 'about');     // any of the given patterns
<a class="nav-link{if 'home'|route_is} active{/if}" href="{navigate name='home'}">Home</a>

HEAD, 404 and 405

A HEAD request matches the GET route. An unknown path answers 404. A path that exists only for other methods answers 405 with an Allow header listing them. Both are thrown as HttpException and rendered by the error handler as HTML or JSON depending on the client.

Trailing slashes and the base path

/about/ and /about are the same route. The base path (the sub-directory the app is installed in) is stripped before matching and prepended when generating URLs, so routes are always written from the application root.

Caching

php console.php route:list      # print the table
php console.php route:cache     # write bootstrap/cache/routes.php
php console.php route:clear

The cache is used whenever APP_DEBUG is off and the file exists. Regenerate it after every deployment that changes routes. Closure actions cannot be serialised; the command refuses to cache them.
