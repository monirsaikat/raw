Models

A model is a row with behaviour: attributes with casts and accessors, relationships, events, scopes and soft deletes. Any static call a model does not define is forwarded to its query builder.

Defining a model

php console.php make:model Post -mf     # model + migration + factory
<?php

class Post extends Model
{
    use SoftDeletes;

    protected static string $table = 'posts';            // default: snake_case plural of the class name
    protected static string $primaryKey = 'id';
    protected static ?string $connection = null;         // a name from config/database.php
    protected static bool $timestamps = true;            // created_at / updated_at

    protected static array $fillable = ['title', 'body', 'meta', 'published_at'];
    protected static array $guarded = ['id'];            // used only when $fillable is empty
    protected static array $hidden = ['secret'];         // left out of toArray()/JSON
    protected static array $visible = [];                // when set, only these are exposed
    protected static array $appends = ['excerpt'];       // accessors included in toArray()
    protected static array $casts = ['meta' => 'array', 'published_at' => 'datetime', 'views' => 'int'];
    protected static array $with = ['author'];           // always eager loaded
}

Creating, updating, deleting

$post = Post::create(['title' => 'Hello', 'body' => '...']);   // only $fillable columns
$post = Post::forceCreate([...]);                                // bypasses $fillable

$post = new Post(['title' => 'Draft']);   $post->body = '...';   $post->save();
$post->update(['title' => 'Renamed']);    $post->fill([...])->save();   $post->forceFill([...]);

$post->delete();     $post->forceDelete();     $post->restore();          // soft deletes
Post::destroy([1, 2, 3]);                                                // by key, firing events
Post::where('published', 0)->delete();                                   // through the builder

Post::firstOrCreate(['slug' => $slug], ['title' => 'New']);
Post::firstOrNew([...], [...]);   Post::updateOrCreate([...], [...]);
$post->increment('views');   $post->decrement('stock', 2);   $post->touch();

Timestamps are set on insert and update. save() only writes attributes that changed, and skips the query entirely when nothing did.

Casts

int/integer, float/double, decimal:2, string, bool/boolean, array/json, object, collection, date, datetime, timestamp. Casting works in both directions: an array cast stores JSON and returns an array; a datetime cast accepts strings or DateTime objects and returns a DateTimeValue. created_at, updated_at and deleted_at are cast to datetime automatically.

Accessors and mutators

public function getExcerptAttribute(): string            // $post->excerpt
{
    return str_limit($this->attributes['body'] ?? '', 80);
}

public function setTitleAttribute($value): void          // $post->title = ' x '
{
    $this->attributes['title'] = trim($value);
}

List computed accessors in $appends to include them in toArray() and JSON.

Relationships

class User extends Model
{
    public function posts(): HasMany      { return $this->hasMany(Post::class); }            // posts.user_id
    public function profile(): HasOne     { return $this->hasOne(Profile::class); }          // profiles.user_id
}

class Post extends Model
{
    public function author(): BelongsTo   { return $this->belongsTo(User::class); }          // posts.author_id (from the method name)
    public function owner(): BelongsTo    { return $this->belongsTo(User::class, 'user_id'); } // explicit foreign key
    public function tags(): BelongsToMany { return $this->belongsToMany(Tag::class)->withPivot('note')->withTimestamps(); }
    public function comments(): HasMany   { return $this->hasMany(Comment::class); }
}

Defaults: hasOne/hasMany look for <parent>_id on the related table; belongsTo uses <method name>_id on this table; belongsToMany uses a pivot table named from both singular model names in alphabetical order (post_tag) with post_id and tag_id. Every key can be passed explicitly.

Eager loading

Loading a relationship for a list of models one by one costs one query per model. with() loads it for all of them in a single extra query:

Post::with('author', 'tags')->get();
Post::with('comments.user')->get();                                     // nested
Post::with(['comments' => fn ($q) => $q->where('approved', 1)->latest()])->get();
$posts->load('tags');   $post->load('comments');   $post->loadMissing('author');

protected static array $with on the model eager loads every time. without('author') removes one for a query.

Querying by relationship

Post::has('comments')->get();                                   // at least one
Post::has('comments', '>=', 3)->get();
Post::has('comments.replies')->get();                           // nested
Post::doesntHave('tags')->get();
Post::whereHas('comments', fn ($q) => $q->where('approved', 1))->get();
Post::whereDoesntHave('comments', fn ($q) => $q->where('spam', 1))->get();
Post::withCount('comments')->get();                             // ->comments_count
Post::withCount(['comments as approved_count' => fn ($q) => $q->where('approved', 1)])->get();
$post->loadCount('comments');

Scopes

// Local: Post::published()->get()
public function scopePublished(QueryBuilder $query): void
{
    $query->whereNotNull('published_at');
}

// Global: applied to every query on the model
protected static function boot(): void
{
    static::addGlobalScope('recent', fn (QueryBuilder $q) => $q->where('created_at', '>', '2020-01-01'));
}

Post::withoutGlobalScope('recent')->get();   Post::withoutGlobalScopes()->get();

Events

Events: retrieved, creating, created, updating, updated, saving, saved, deleting, deleted, restoring, restored, forceDeleting, forceDeleted. Returning false from a …ing listener cancels the operation.

protected static function boot(): void
{
    static::creating(fn (Post $post) => $post->slug ??= str_slug($post->title));
    static::deleting(fn (Post $post) => $post->comments()->delete());
}

Post::listen('updated', fn (Post $post) => cache_forget('post.' . $post->id));
Post::observe(PostObserver::class);          // an object with methods named after events

Model::withoutEvents(fn () => Post::create([...]));
$post->saveQuietly();

Soft deletes

Add use SoftDeletes; and a nullable deleted_at column ($table->softDeletes()). delete() then stamps the row instead of removing it, and a global scope hides stamped rows everywhere.

$post->delete();   $post->trashed();   $post->restore();   $post->forceDelete();
Post::withTrashed()->get();   Post::onlyTrashed()->get();   Post::withoutTrashed()->get();
Post::where('id', 3)->delete();          // soft-deletes through the builder too
Post::where('id', 3)->forceDelete();

Serialisation

$post->toArray();       // attributes (cast, minus $hidden, plus $appends) and loaded relationships
$post->toJson();        json_encode($post);        return $post;   // from an action → JSON response

Connections

Set protected static ?string $connection = 'reports'; or use Post::on('reports') for one query. Relationships and pivot operations follow the related model's connection.
