Authentication

Session-based login with hashed passwords, remember-me cookies, intended-URL redirects and throttling. The app ships with working register, login and logout flows to copy from.

Configuration

config/auth.php:

'model' => 'User',               // the authenticated model
'username' => 'email',           // column matched by auth_attempt()
'session_key' => 'auth_id',
'login_route' => 'login',        // where the auth middleware sends guests
'home_route' => 'home',          // where the guest middleware sends users
'policies' => [],                // see Authorization
'remember' => ['cookie' => 'remember_me', 'days' => 30],

Helpers

auth_check();   auth_guest();   auth_id();   auth_user();          // User|null, loaded once per request
auth_attempt($email, $password, remember: true);                    // bool
auth_login($user);   auth_login($userId, remember: true);
auth_logout();
auth_intended('/dashboard');                                        // Response: redirect to the page the user wanted, else the default

auth_attempt() looks the user up by the username column, verifies the password against a dummy hash when the user does not exist so timing does not reveal accounts, re-hashes passwords made with an outdated algorithm, and logs the user in. Logging in rotates the session ID.

The User model

class User extends Model
{
    use Authorizable;

    protected static array $fillable = ['name', 'email', 'password'];
    protected static array $hidden = ['password', 'remember_token'];

    public static function hashPassword(string $password): string;
    public function verifyPassword(string $password): bool;
    public static function findByEmail(string $email): ?static;
}

Passwords are stored with password_hash() (bcrypt by default). $hidden keeps the hash and the remember token out of JSON.

Registration

public function register()
{
    $data = validated(input(), [
        'name' => 'required|max:100',
        'email' => 'required|email|max:150|unique:users,email',
        'password' => 'required|min:8|confirmed',
    ], ['email.unique' => 'An account with this email already exists.']);

    $user = User::create([
        'name' => $data['name'],
        'email' => $data['email'],
        'password' => User::hashPassword($data['password']),
    ]);

    auth_login($user);

    return redirect_route('account');
}

Login and logout

public function login()
{
    $data = validated(input(), ['email' => 'required|email', 'password' => 'required']);

    if (!auth_attempt($data['email'], $data['password'], has_input('remember'))) {
        return back_with_errors(['email' => ['Those credentials do not match our records.']]);
    }

    return auth_intended(route_url('account'));
}

public function logout()
{
    auth_logout();

    return redirect_route('home');
}
group(['middleware' => ['guest']], function () {
    get('/login', 'AuthController@showLogin', 'login');
    post('/login', 'AuthController@login', 'login.store', ['throttle:5,1']);
});

group(['middleware' => ['auth']], function () {
    get('/account', 'AuthController@account', 'account');
    post('/logout', 'AuthController@logout', 'logout');
});

Logout is a POST so it is covered by CSRF protection; the layout renders it as a small form.

Middleware

  • auth: guests are redirected to the login route. For GET requests the requested URL is stored so auth_intended() can return there after login. Clients asking for JSON receive a 401 instead.
  • guest: logged-in users are sent to the home route.
  • throttle:5,1: five attempts per minute per IP, then 429.

Remember me

With remember: true a random token is generated, its HMAC (keyed with APP_KEY) is stored in users.remember_token, and a cookie id|token is sent for thirty days. On a later visit without a session the cookie is verified in constant time and the user is logged in with a fresh session ID. Logging out clears both the column and the cookie. The users table needs the column: $table->rememberToken().

In templates

{if $auth_user}
    <a href="{navigate name='account'}">{$auth_user.name}</a>
    <form method="post" action="{navigate name='logout'}">{csrf_field}<button>Log out</button></form>
{else}
    <a href="{navigate name='login'}">Log in</a>
{/if}

Testing

test('a user can log in', function () {
    $user = User::factory()->create(['email' => 'a@b.co']);        // factory password: "password"

    http_post('/login', ['email' => 'a@b.co', 'password' => 'password'])
        ->assertRedirect('/account')
        ->assertAuthenticated($user);
});

test('protected pages need a user', function () {
    http_get('/account')->assertRedirect('/login');
    acting_as(User::factory()->create());
    http_get('/account')->assertOk();
});
