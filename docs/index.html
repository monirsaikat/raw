ComfreePHP

ComfreePHP is a dependency-free PHP 8.3 framework: procedural helpers where that reads best, classes where state matters. Smarty 5 templates, PDO on MySQL/MariaDB or SQLite, Bootstrap self-hosted. No Composer, no CDNs, nothing to install beyond PHP.

What you get

  • HTTP: a router with constraints, groups and caching; controllers with dependency injection and route model binding; validation with thirty-five rules; Smarty views that escape by default.
  • Data: named connections, a query builder with sub-queries and unions, collections, pagination, an ORM with four relationship types and eager loading, a schema builder, migrations, factories and seeders.
  • Services: sessions, flash messages, a file cache, rate limiting, authentication with remember-me, policies and gates, a dependency injection container, structured logging and a debug page.
  • Tooling: a console with generators and database commands, and a test runner with an in-process HTTP client that exercises the real application against in-memory SQLite.

Design in one paragraph

Every request enters through index.php, which loads core/bootstrap.php. Bootstrap reads .env and config/, installs the error handlers, loads the core modules and your middleware, then route() matches the request, runs the middleware chain and calls the action through the container. Whatever the action returns (a string from view(), an array, a model, or a Response) is sent. Anything thrown is caught by the exception handler and turned into an error page, a redirect back with validation errors, or a JSON payload, depending on the client.
