CComfreePHP docs

Console

php console.php <command> [arguments] [--option=value]. Run it without arguments for the list. Options may be written as --name=value, --flag, or short flags such as -mf.

Adding a command

Commands are registered in console.php with command(name, description, handler). The handler receives the raw arguments and returns an exit code; parse_arguments() splits them into positional values and options.

command('users:prune', 'Delete accounts inactive for N days [--days=90] [--dry]', function (array $args) {
    [$positional, $options] = parse_arguments($args);
    $days = (int) ($options['days'] ?? 90);

    $query = User::where('last_login_at', '<', now()->subDays($days));
    line($query->count() . ' users to prune');

    if (!isset($options['dry'])) {
        line('Deleted ' . $query->delete());
    }

    return 0;
});

Helpers available inside handlers: line(), error_line(), print_table($headers, $rows), confirm($question), write_stub($path, $contents), relative_path(), and everything the application offers (models, Database, config()…). Bootstrap has already run, so .env and the container are loaded.
