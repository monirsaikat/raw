Mail

Emails are Mailable classes in mail/ rendered from Smarty templates in views/mail/, sent through a transport chosen in config/mail.php: a raw-socket SMTP client, PHP's mail(), the log file (the development default) or an in-memory array for tests. No external library.

Configuration

MAIL_MAILER selects the mailer; the SMTP settings and the default sender come from the other MAIL_* variables in .env. With the default log mailer every message lands in storage/logs/app-YYYY-MM-DD.log, headers and all, so nothing leaves a development machine.

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_ENCRYPTION=tls        # tls = STARTTLS, ssl = implicit TLS (465), empty = plain
MAIL_USERNAME=postmaster
MAIL_PASSWORD=secret
MAIL_FROM_ADDRESS=hello@example.com
MAIL_FROM_NAME="${APP_NAME}"

Check the setup end to end with php console.php mail:test you@example.com (add --mailer=smtp to try a mailer other than the default).

Writing a mailable

php console.php make:mail OrderShipped creates mail/OrderShipped.php and views/mail/order_shipped.tpl. Configure the message in build() with the fluent setters; constructor arguments carry the data.

class OrderShipped extends Mailable
{
    public function __construct(private Order $order) {}

    public function build(): void
    {
        $this->subject('Order #' . $this->order->id . ' shipped')
            ->view('mail/order_shipped', ['order' => $this->order])
            ->text('Your order ' . $this->order->id . ' is on its way.')   // plain-text alternative
            ->replyTo('support@example.com', 'Support')
            ->attach(BASE_PATH . '/storage/invoices/' . $this->order->id . '.pdf', 'invoice.pdf')
            ->attachData($csv, 'items.csv', 'text/csv')
            ->priority(1);
    }
}

Setters: to, cc, bcc, replyTo (each accepts 'a@b.c', 'a@b.c', 'Name', ['a@b.c', 'd@e.f'], ['a@b.c' => 'Ann'] or ['address' => ..., 'name' => ...]), from, subject, view(template, data), with(key, value), text, html (raw markup instead of a template), attach(path, name?, mime?), attachData(data, name, mime), header, priority(1-5). render() returns the HTML body for previewing in a route; toMessage() produces the MailMessage value object the transports consume.

Templates

Mail templates are ordinary Smarty views with the same globals ($app_name, {current_year}, auto-escaping) plus $subject. views/mail/layout.tpl is a table-based responsive layout with header, content and footer blocks; extend it and fill content.

{extends file='mail/layout.tpl'}

{block name='content'}
    <h1 style="margin:0 0 16px;font-size:22px;">Welcome, {$name}!</h1>
    <p><a href="{$url}">Open your account</a></p>
{/block}

Use absolute URLs in emails: app_url() . '/account' rather than url(), which is relative to the web root.

Sending

Mail::to($user->email, $user->name)->send(new WelcomeMail($user->name));
Mail::to(['a@example.com', 'b@example.com'])->cc('boss@example.com')->send(new OrderShipped($order));
Mail::send((new OrderShipped($order))->to($customer->email));   // recipients set on the mailable
Mail::raw('ops@example.com', 'Disk almost full', "92% used on web-1\n");
Mail::send($mailable, 'smtp');                                  // a specific mailer
Mail::queue(new OrderShipped($order));                          // SendMailJob on the queue, or sent now without it

Mail::send() returns the MailMessage that went out and fires the mail.sent event with the mailable and message. Delivery problems throw a RuntimeException with the SMTP reply in the message; nothing is swallowed.

Transports

MailerClassNotes
smtpSmtpTransportstream_socket_client, EHLO, STARTTLS via stream_socket_enable_crypto or implicit TLS, AUTH LOGIN / PLAIN, per-command timeouts, dot-stuffing. One connection per message.
sendmailSendmailTransportPHP mail(): the sendmail binary or the SMTP settings in php.ini.
logLogTransportWrites the full RFC 5322 message to the application log. Development default.
arrayArrayTransportKeeps MailMessage objects in memory (mailer()->messages()). Used by Mail::fake().

MimeBuilder turns a MailMessage into wire format: quoted-printable text and HTML parts inside multipart/alternative, wrapped in multipart/mixed with base64 parts when there are attachments, RFC 2047 encoding for non-ASCII subjects and display names, and CR/LF stripped from every header value so user input cannot inject headers. A custom transport is any class implementing MailTransport; register it under a mailer name with mail_use('api', new ApiTransport()) or bind the transport name in config/container.php.

Testing

Mail::fake() routes every send into memory and records the mailables. Filters receive the mailable, so assertions can inspect recipients (hasTo(), hasCc(), hasBcc()) and constructor data. Mail::sentMessages() exposes the rendered messages for checking the subject or body.

test('registration sends the welcome mail', function () {
    Mail::fake();

    http_post('/register', ['name' => 'Ann', 'email' => 'ann@example.com', ...]);

    Mail::assertSent(WelcomeMail::class, fn (WelcomeMail $mail) => $mail->hasTo('ann@example.com'));
    Mail::assertNotSent(OrderShipped::class);
    assert_contains('Welcome, Ann', Mail::sentMessages()[0]->html);
});

test('nothing is sent on validation errors', function () {
    Mail::fake();
    http_post('/register', []);
    Mail::assertNothingSent();
});

The test runner does not reset the fake between tests; call mail_reset() (drops cached transports and restores the real facade) in after_each(). Set config_set('mail.default', 'array') in a test that wants to exercise a real transport without touching the log.
